Claude Startkit

Vijf prompts om zelf met AI aan de slag te gaan in je bedrijf. Kopieer, plak in Claude en vul de [gemarkeerde stukjes] zelf in.

Zo begin je

  1. Maak een account op claude.aiGratis kan, daarmee kun je alle prompts hieronder gebruiken.
  2. Maak een project voor je bedrijfAlles wat je in dat project zet, gebruikt Claude in elk gesprek als context.
  3. Begin bij prompt 1 of 2Ken je Claude al? Sla prompt 1 over en start met je bedrijfsprofiel.

Tip: de 5 taken die je tijdens de sessie opschreef zijn het perfecte startpunt voor prompt 3.

Prompt 1

Leer Claude kennen

Wanneer: je hebt Claude nog nauwelijks gebruikt.

Ik ben ondernemer en wil leren werken met Claude. Ik heb [geen / een beetje / veel] ervaring met AI en geen programmeerervaring. Mijn bedrijf: [wat je doet, in één zin].

Leg me in simpele taal uit:
1. Wat Claude is en wat ik er als ondernemer mee kan
2. Wat projecten zijn en hoe ik context geef, zodat je mij beter helpt
3. Wat Claude Code is, wat het verschil is met de gewone chat en wanneer ik het nodig heb
4. Hoe ik Claude Code installeer en mijn eerste kleine project start

Behandel één punt tegelijk en geef bij elk punt een voorbeeld dat bij mijn bedrijf past. Check met een korte vraag of ik het snap en ga pas door als ik dat zeg. Zoek actuele informatie op als je twijfelt of iets nog klopt.
Prompt 2

Maak je bedrijfsprofiel

Wanneer: één keer, als basis. Zet de uitkomst in je project.

Ik ben eigenaar van [naam van je bedrijf]. Ik wil een bedrijfsprofiel maken dat ik als vaste context aan Claude kan geven, zodat je me in elk gesprek beter helpt.

Interview me. Stel één vraag tegelijk en wacht op mijn antwoord. Vraag in ieder geval naar:
- wat mijn bedrijf doet en wat ik verkoop
- wie mijn klanten zijn en waarom ze bij mij kopen
- hoe ik werk en met wie (team, partners, leveranciers)
- welke tools, kanalen en software ik gebruik
- mijn doelen voor het komende jaar
- hoe ik schrijf en met klanten communiceer

Vraag door als een antwoord vaag is. Als je genoeg weet, maak je een overzichtelijk bedrijfsprofiel met kopjes dat ik in een Claude-project kan zetten. Verzin niets wat ik niet heb verteld.
Prompt 3

Vind je AI-kansen

Wanneer: na prompt 2. Plak je bedrijfsprofiel erin.

Ik ben eigenaar van [naam van je bedrijf]. [Plak hier je bedrijfsprofiel uit prompt 2, of beschrijf in een paar zinnen wat je bedrijf doet.]

Ik wil ontdekken waar AI mij tijd kan besparen of mijn bedrijf beter kan maken. Mijn ervaring met AI: [geen / een beetje / veel].

Stel me eerst vragen over hoe mijn week eruitziet, welke taken ik niet leuk vind, wat veel tijd kost en waar ik tegenaan loop. Stel één vraag tegelijk en vraag door waar nodig. Ik geef zo uitgebreid mogelijk antwoord.

Als je genoeg weet, geef je me:
1. Een lijst met taken die ik met AI kan automatiseren of verbeteren, gesorteerd op tijdwinst
2. Per taak: wat de oplossing is, welke tool je zou gebruiken en hoe moeilijk het is
3. De ene taak waarmee ik het beste kan beginnen, met de eerste drie stappen
Prompt 4

Van idee naar tool

Wanneer: je weet wat je wilt bouwen en wilt stap voor stap meegenomen worden.

Ik wil iets bouwen voor [naam van je bedrijf]: [beschrijf je idee, bijvoorbeeld een overzicht van al mijn offertes of een automatisch antwoord op veelgestelde klantvragen].

Ik heb geen programmeerervaring, dus leg alles simpel uit.

Stel me eerst vragen tot je precies snapt wat ik nodig heb. Stel één vraag tegelijk, ik geef zo uitgebreid mogelijk antwoord. Stel daarna een aanpak voor, leg uit waarom, en zeg of ik dit in de gewone chat kan maken of beter met Claude Code.

Neem me daarna stap voor stap mee. Leg bij elke stap uit wat ik moet doen en waarom, en ga pas verder als ik zeg dat het gelukt is.
Prompt 5

Kritische sparringspartner

Wanneer: je twijfelt over een beslissing of een plan.

Ik twijfel over een beslissing voor [naam van je bedrijf]: [beschrijf de keuze].

Help me dit goed te doordenken. Stel me eerst vragen over de situatie, één tegelijk. Benoem daarna de risico's, de zwakke plekken in mijn redenering en wat ik over het hoofd zie. Wees eerlijk, ook als je denkt dat ik de verkeerde kant op ga. Geef pas aan het eind je advies, met de belangrijkste reden erbij.

Alle prompts werken met een gratis account. Claude Code zelf vraagt om een betaald abonnement.
